# ELA-Guided LLM Benchmark

A benchmark for evaluating Large Language Models (LLMs) on generating optimization functions based on Exploratory Landscape Analysis (ELA) features.

## Overview

This project benchmarks the ability of LLMs (like Gemini, OpenAI) to generate optimization functions matching specific ELA characteristics. ELA features describe the landscape properties of optimization problems, and this tool tests how well LLMs can generate functions with targeted properties.

## Features

- Zero-shot and few-shot function generation experiments
- ELA feature extraction and comparison
- Visualization of generated vs. target functions
- Support for multiple LLM providers (Gemini, OpenAI)
- Benchmarking against BBOB test functions
